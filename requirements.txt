Install with: pip install -r requirements.txt

pyTelegramBotAPI>=4.14.0

HTTP requests, redirects and proxy fetching

requests>=2.31.0

SOCKS4/SOCKS5 proxy support

PySocks>=1.7.1

pycryptodome>=3.19.0
